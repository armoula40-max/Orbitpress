# OrbitPress Server Edition

نسخة السيرفر من OrbitPress: نفس واجهة التطبيق الأصلية، تعمل من المتصفح، مع
**سكرابر مدمج** لـ Facebook و Pinterest (بأسلوب FeedSpy) — **بدون أي API خارجي
وبدون رفع كوكيز**. تسجيل الدخول للمنصتين يتم بنقرة واحدة من صفحة الإعدادات عبر
متصفح Chromium دائم يعمل داخل السيرفر.

## المتطلبات

- Node.js 20 أو أحدث (أو Docker)
- متصفح Chromium للماسح: `npm run install-browser`

## التشغيل

```bash
cd server
npm install
npm run install-browser    # مرة واحدة: ينزّل Chromium المستخدم بالماسح
npm start                  # يعمل على المنفذ 8080
```

ثم افتح `http://عنوان-السيرفر:8080/` من أي متصفح (كمبيوتر أو هاتف).

### متغيرات البيئة

| المتغير | الوظيفة |
|---|---|
| `PORT` / `HOST` | منفذ ومضيف الاستماع (الافتراضي 0.0.0.0:8080) |
| `ORBITPRESS_TOKEN` | رمز دخول للواجهة — **فعّله حتماً على سيرفر عام** |
| `ORBITPRESS_DATA_DIR` | مجلد البيانات (الافتراضي `server/data`) |
| `ORBITPRESS_SECRET_KEY` | مفتاح AES-256 64-hex لتشفير الأسرار (يُولَّد تلقائياً إذا غاب) |

### Docker

**على سيرفر أوبونتو (الطريق الأسرع):**

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/armoula40-max/Orbitpress/arena/01a08173-orbitpress/server/deploy/install-server.sh)
```

الدليل الكامل بالتفصيل (أمان، تحديث، نسخ احتياطي، Tailscale): [`docs/DEPLOY_VPS_AR.md`](../docs/DEPLOY_VPS_AR.md)

**يدوياً من جذر المستودع:**

```bash
cp server/.env.example .env   # ثم ضع ORBITPRESS_TOKEN داخله
docker compose up -d --build
```

## ما الذي تغيّر عن نسخة أندرويد؟

| في أندرويد | في نسخة السيرفر |
|---|---|
| WebView يمسح بحساب الهاتف | Chromium مدمج في السيرفر مع جلسة دائمة |
| سكرابر VPS خارجي + رفع كوكيز | سكرابر مدمج هجين (HTTP ثم متصفح) — لا شيء مطلوب |
| زر "Visible scan" | يعمل الآن من السيرفر مباشرة |
| الإشعارات/WorkManager | مجدول دائم على السيرفر يجهّز المسودات (النشر يدوي دائماً) |
| تخزين مشفر على الهاتف | تشفير AES-256-GCM للأسرار في `data/settings.json` |

## SEO احترافي 100/100 (Yoast + Rank Math)

- التوليد يُنتج: كلمة مفتاحية أساسية + 5–8 كلمات ثانوية، عنوان SEO (≤60 حرفًا
  تبدأ به الكلمة)، وصف Meta (50–160 حرفًا)، أسئلة «people also ask»، مقالات
  ≥1200 كلمة ومجموعات وصفات ≥900 كلمة، توزيع طبيعي للكلمة (0.5–2.5٪) في
  الفقرة الأولى و30–40٪ من العناوين وأحد النصوص البديلة، وروابط داخلية حقيقية
  (تُطابَق مع مقالات الموقع الفعلية عبر REST) وروابط خارجية بعد التحقق الحيّ
  من وجودها على ويكيبيديا (قابلة للإيقاف من الإعدادات).
- مخطط JSON-LD: `Recipe` صريح للوصفة الواحدة، و`@graph` يحوي `ItemList` +
  عقد `Recipe` كاملة للمجموعات — به تظهر الدبابيس كـ **وصفات على Pinterest**
  ونتائج غنية على جوجل. لا تُختلق تقييمات أو سعرات أو قيم غذائية إطلاقًا.
- شاشة المراجعة تعرض محللًا حيًّا بالعربية يحاكي معايير Rank Math/Yoast،
  وبوابة نشر لينة تمنع النشر تحت 100/100 مع زر تأكيد ثانٍ للنشر رغم التحذيرات.
- **جسر SEO** (إضافة وردبريس ملف واحد، بدون تتبّع أو اتصالات خارجية):
  تنزيلها من الخادم نفسه عبر `/downloads/seo-bridge-plugin`، أو من
  `wordpress/orbitpress-seo-bridge/` في المستودع، مع دليل التثبيت
  `README_AR.md` داخل المجلد. بدونها يكتب ووردبريس حقول Yoast/Rank Math عبر
  REST؛ ينبّه التقرير بعد النشر ويُقدّم رابط التنزيل.

## محلل FeedSpy الجديد (Facebook + Pinterest)

- **فلترة بفترة زمنية**: 7/30/90 يوم أو نطاق مخصص — المنشورات بلا تاريخ تخرج من فلاتر الفترة (مثل FeedSpy).
- **ترتيب**: الأكثر فيروسية (Viral Score 0–100)، التفاعلات، الحفظ، التعليقات، المشاركات، الأحدث، الأقدم.
- **بحث داخل النتائج** بأي كلمة أو عبارة.
- **فلاتر حد أدنى/أقصى** على أي مقياس.
- **إخفاء المشاهَد** مع تعليم يدوي وتذكّر محلي.
- **إحصاءات فورية**: متوسط التفاعل، مجموع التفاعل، أفضل توقيت (يوم/ساعة UTC)، رسم النشاط الأسبوعي.
- **تصدير CSV** — يفتح في Excel مباشرة.
- **تقرير AI شامل بالعربية**: لماذا نجحت المنشورات، الأنماط الفيروسية، الكلمات المفتاحية، زوايا المحتوى، وخطة عمل.

## ملاحظات مهمة عن الماسح

- الماسح يقرأ المحتوى العام (أو المتاح لجلستك) ولا يتجاوز CAPTCHA أو التحقق بخطوتين.
- Pinterest: يعمل بدون تسجيل دخول لمعظم الصفحات العامة، والدخول يحسّن التغطية.
- Facebook: من عنوان IP سيرفر (datacenter) غالباً يتطلب جلسة متصلة — سجّل الدخول من الإعدادات.
- كل النتائج تُعرض مع طريقة الجمع (`collectionMethod`) ودرجة الاكتمال.

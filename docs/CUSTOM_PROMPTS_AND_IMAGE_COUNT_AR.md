# تخصيص موجهات التوليد وعدد الصور

أضيفت إلى Settings بطاقة **Custom generation prompts** لكل موقع، وتحتوي على:

- موجه المقال النصي.
- موجه صور المقال.
- موجه صورة Pinterest.
- عدد الصور الإضافية داخل المقال من صفر إلى ثماني صور.

يمكن استخدام المتغيرات التالية داخل الموجهات:

| المتغير | القيمة |
|---|---|
| `{{keyword}}` | الكلمة المفتاحية الحالية. |
| `{{category}}` | تصنيف WordPress المختار. |
| `{{title}}` | عنوان المسودة أو المقال. |

## سلوك موجه المقال

يضاف الموجه المخصص إلى تعليمات التوليد مع الحفاظ على عقد JSON الإلزامي وقواعد تنظيف HTML واكتمال الوصفات. لذلك يجب أن يصف الموجه الأسلوب والصوت والجمهور، ولا ينبغي أن يطلب تغيير أسماء الحقول أو إعادة المقال بصيغة Markdown.

## سلوك موجهات الصور

يستخدم موجه صور المقال للصور البارزة والصور الإضافية. ويستخدم موجه Pinterest للصورة العمودية. يظل فحص Pinterest بنسبة 2:3 فعالاً مهما كان الموجه المخصص.

## عدد الصور داخل المقال

عند ضبط العدد على قيمة أكبر من صفر يظهر زر **Generate additional article images** في شاشة Review. يحفظ التطبيق الصور محلياً، ثم يرفعها إلى WordPress عند نشر المقال ويضيفها كصور داخلية بعد محتوى المقال.

الصورة Featured وصورة Pinterest مستقلتان عن عدد الصور الإضافية. لذلك، إذا كانت القيمة `3`، فسيكون التدفق: صورة Featured، وثلاث صور داخل المقال، وصورة Pinterest منفصلة.

## الحدود

الحد الأعلى الحالي ثماني صور إضافية لكل مقال لتقليل استهلاك API وحجم الطلبات. لم يتم تنفيذ طلب حقيقي إلى مزود صور أثناء تعديل المصدر. يجب اختبار الموجهات مع مزودك الفعلي، لأن جودة الالتزام بالموجه تختلف من نموذج إلى آخر.

## إعداد التوكنات

تظل مفاتيح Article API وImage API وPinterest داخل التخزين المشفر لكل موقع. لا تدخل هذه المفاتيح في النسخ الاحتياطي المحلي ولا في سجل النشاط.
